## 🎯 Overview

A modern, responsive Learning Management System (LMS) frontend application built with Next.js 14. This platform provides a seamless learning experience with intelligent course discovery powered by DeepSeek AI search technology.

## ✨ Features

### 🎓 Core Features
- **AI-Powered Search** - Intelligent course and content search using DeepSeek AI
- **Course Management** - Browse, filter, and enroll in courses
- **Interactive Dashboard** - Personalized learning progress tracking
- **Video Lectures** - High-quality video playback with progress tracking
- **Quizzes & Assessments** - Interactive testing with instant feedback
- **Certificates** - Auto-generated completion certificates

### 🔍 DeepSeek Integration
- Semantic search for courses and learning materials
- Intelligent content recommendations
- Natural language query processing
- Context-aware search results

### 🎨 UI/UX Features
- **Responsive Design** - Optimized for desktop, tablet, and mobile devices
- **Dark/Light Mode** - Theme switching with system preference detection
- **Smooth Animations** - Engaging micro-interactions and transitions
- **Accessibility** - WCAG 2.1 compliant components
- **Real-time Updates** - Live notifications and progress sync

### ⚡ Technical Features
- **Server-Side Rendering (SSR)** - Fast initial page loads
- **Static Site Generation (SSG)** - Pre-rendered course pages
- **API Routes** - Backend integration endpoints
- **Middleware** - Authentication and route protection
- **Image Optimization** - Automatic image optimization with Next.js Image component
